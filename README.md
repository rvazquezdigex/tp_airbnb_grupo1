## Instrucciones de ejecución

1. Crear el entorno virtual e instalar dependencias (desde la carpeta del proyecto):
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt

2. Descargar listings.csv.gz y colocarlo dentro de la carpeta data
3. Correr los dos proyectos (con el entorno activado):
   python correr_tp.py
   Guarda los gráficos en la carpeta graficos.
